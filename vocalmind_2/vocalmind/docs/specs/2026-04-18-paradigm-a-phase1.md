> **문서 버전**: 1.0 | **작성일**: 2026-04-18 | **작성자**: APEX (Planner)
> **기간**: 3개월 | **목표**: $250K MRR, 유료 크리에이터 1만명

## 1. 제품 정체성 & 가치 제안

### 한 문장 정의
**"연습하면 자동으로 뮤직비디오가 찍히고, 졸업하면 유튜버가 되어 있는 유일한 보컬 플랫폼."**

### 가치 제안
HLB 보컬스튜디오는 "보컬 학원"에서 "AI 커버 아티스트 공장"으로 포지션을 확장한다. 유저가 28단계 커리큘럼을 밟는 동안 수집된 본인 음색 데이터를 기반으로, 플랫폼이 자동으로 ① 본인 음색의 K-POP 커버 ② 곡 분위기에 맞는 뮤직비디오 ③ 가로/세로 멀티포맷 ④ 유저 계정 자동 업로드 ⑤ 성과 리포트까지 원클릭으로 수행한다. 유저는 "배우는 중에 이미 유튜버"가 된다.

### 경쟁 포지셔닝

| 경쟁 제품 | 강점 | 약점 | Paradigm A의 차별점 |
|---|---|---|---|
| **Suno / Udio** | 텍스트→완성곡 AI | "내 목소리"가 아님, MV 없음, 커리큘럼 없음 | 내 음색 + MV + 성장 서사 |
| **Smule / StarMaker** | 노래방 커뮤니티 | AI 보정·MV 없음, 숏폼 출고 없음 | 실력 성장 + 자동 데뷔 |
| **Kits AI / Voicify** | RVC 음색 변환 | 교육·커리큘럼 없음, MV 없음 | 수료 → 데뷔 풀스택 |
| **기존 보컬 앱(Vanido 등)** | 피치 트레이닝 | "수료 후" 출구 없음 | 수료 = 유튜버 데뷔 |

**전략적 해자**: Suno는 "곡을 만든다", 우리는 **"내가 가수가 된다"**. 학습 데이터 = 본인 목소리 = 경쟁자가 복제 불가능한 자산.

### 시장 검증 (2026-04 리서치)
- 글로벌 voice cloning 시장 $1.1~1.2B / CAGR 24~26%
- AI 음악 수익화가 2026 핵심 트렌드 (로열티, 데이터 기반 라이선스, 크리에이터 소유 AI 모델)
- AI MV가 인디 아티스트의 2주 데뷔를 가능하게 하는 민주화 촉매

## 2. 타깃 유저 페르소나

### 페르소나 1: 데뷔 꿈 학생 — 지유 (19세, 여, 서울)
- **배경**: 실용음악과 입시 준비. 학원비 월 60만원. 데뷔 포트폴리오 갈증.
- **고통**: 완성된 결과물이 없음 / 데모 MV 제작비 200만원 / 커버 1편 찍는 데 주말 하루
- **해결**: 10단계만 마쳐도 자동 MV 월 4편 → SNS 자동 업로드 → 입시용 포트폴리오 자동 축적
- **지불 의사**: Creator $79/월 (학원비 대비 1/10)

### 페르소나 2: 숏폼 크리에이터 — 민재 (27세, 남, 직장인)
- **배경**: 틱톡 팔로워 8천, 노래 커버 주 1회, 본업 병행
- **고통**: 편집 1편에 3~5시간 / 음색 불만 / 주 3회 업로드 불가능
- **해결**: 녹음 5분 → 30분 내 3개 플랫폼 동시 게시. 주 5편 가능.
- **지불 의사**: Pro $199/월 (광고 수익 분배 기대)

### 페르소나 3: 보컬 취미인 — 수진 (35세, 여, 워킹맘)
- **배경**: 노래방 애호, 동호회, 가끔 인스타 커버 업로드
- **고통**: 동호회 공연 영상 외주 30만원 / 내 목소리가 더 멋지면 좋겠음
- **해결**: 매달 자동 MV 1편 → 가족·지인 공유 → 자존감
- **지불 의사**: Starter $30/월

## 3. 핵심 유저 플로우 — "수료 → 데뷔" 파이프라인

### 첫 곡 완성까지 목표: **≤ 15분** (녹음 5분 + 렌더 10분, 백그라운드 알림)

| Step | 화면 | 유저 액션 | 시스템 백그라운드 |
|---|---|---|---|
| 1. 진입 | `/studio` | "커버 만들기" 클릭 | 크레딧 확인, 무료 체험 판정 |
| 2. 곡 선택 | `/studio/new` | 라이선스 MR 카탈로그 or 본인 MR 업로드 | 곡 메타(BPM/키/장르/무드) 로드 |
| 3. 녹음 | `/studio/new?step=record` | 가이드 보컬 녹음 | 실시간 피치·긴장 측정 |
| 4. 보컬 처리 | 로딩 | 대기 (~2분) | RVC 보정 + 피치 교정 + 반주 믹싱 |
| 5. MV 스타일 | `/studio/new?step=style` | 4종 프리셋 택1 or "AI 추천" | 곡 무드→프리셋 자동 추천 |
| 6. 아바타 | 같은 화면 | 본인 사진 아바타 / 실사 / 애니 택1 | 아바타 정적 자산 로드 |
| 7. MV 생성 | 진행률 바 + 알림 | 대기 or 이탈 가능 | FLUX 씬 생성 → HunyuanVideo 애니 → LatentSync 립싱크 → 편집·자막·포맷 |
| 8. 프리뷰 | `/studio/[coverId]` | 미리보기, 썸네일/씬 재생성, 제목 작성 | 씬 단위 재생성 |
| 9. 업로드 설정 | `/studio/[coverId]/publish` | 플랫폼 선택, 공개범위, 예약 | OAuth 확인, 저작권 체크 |
| 10. 자동 게시 | 체크리스트 | "게시 시작" | 각 플랫폼 API 동시 업로드 + 재시도 |
| 11. 성과 추적 | `/dashboard/creator` | 조회·좋아요·댓글 확인 | 24시간마다 통계 수집 |
| 12. 다음 곡 유도 | 대시보드 배너 | "다음 곡 만들기" | 패턴 기반 곡 추천 + 크레딧 리필 유도 |

## 4. 신규 기능 목록

### F1: AI 스튜디오 원클릭 파이프라인 [P0]
- **시나리오**: MR + 녹음 + 스타일 선택만 하면, 보컬 보정 → MV 생성 → 편집 → 멀티포맷까지 자동
- **완료 기준**:
  - [ ] 평균 10분 이내 가로/세로 2개 MV 파일 생성
  - [ ] 동시 처리 100건 에러율 5% 미만
  - [ ] 단일 커버 원가 $1.5 이하 (마진 70%+)
  - [ ] 생성 실패 시 크레딧 자동 환불 + 재시도
- **엣지 케이스**:
  - SNR < 10dB 저품질 녹음 → 재녹음 요청
  - MR-녹음 길이 불일치 → 자동 정렬 or 경고
  - GPU 대기 10분 초과 → 이메일 알림 전환

### F2: 개인 음색 모델 (Voice Identity) [P0]
- **시나리오**: 5분 등록 플로우 or 커리큘럼 녹음 누적으로 본인 전용 RVC 모델 보유
- **완료 기준**:
  - [ ] 등록 플로우 5분 이내 (30초 × 10문장)
  - [ ] 학습 대기 30분 이내
  - [ ] 원본 음색 보존도 MOS 3.5/5.0 이상
  - [ ] 계정 귀속, 타 유저 음색 사용 차단
- **엣지 케이스**:
  - 녹음 데이터 부족 → 임시 범용 모델 + 커리큘럼 진행 중 자동 수집
  - 변성기 검출 → 블록

### F3: MV 비주얼 스타일 엔진 [P0]
- **시나리오**: BPM/키/장르/무드 분석 → 4~8개 씬 프리셋 자동 추천
- **완료 기준**:
  - [ ] 4종 프리셋 (시네마틱/포근/도시야경/판타지)
  - [ ] 무드→프리셋 추천 정확도 70% 이상
  - [ ] 씬 이미지 5초, 영상 클립 30초 이내
  - [ ] 가로(16:9) + 세로(9:16) 일관성
- **엣지 케이스**:
  - 가사 금지어 → 안전 필터로 대체
  - "AI 느낌 싫음" → 실사 톤만 노출

### F4: 아바타·립싱크 통합 [P0]
- **시나리오**: 본인 얼굴 or AI 아바타가 MV 안에서 노래 부르는 것처럼
- **완료 기준**:
  - [ ] 사진 1장→아바타 3분 이내
  - [ ] 립싱크 정확도 4.0/5.0 이상
  - [ ] "무얼굴 모드" 지원
  - [ ] NSFW·미성년·타인 얼굴 자동 차단
- **엣지 케이스**:
  - 저해상도 → 고해상화 전처리
  - 유명인 유사도 80% 초과 → 차단 + 경고

### F5: 크레딧 & 구독 결제 [P0]
- **완료 기준**:
  - [ ] 크레딧 실시간 표시, 선차감 + 실패 복구
  - [ ] 3티어 + 크레딧 충전 병행
  - [ ] 토스페이먼츠 + Stripe 2PG
  - [ ] 구독 취소/환불 정책, 잔여 크레딧 60일 유효

### F6: 자동 SNS 멀티 업로드 [P0]
- **완료 기준**:
  - [ ] OAuth 각 플랫폼 3분 이내
  - [ ] 업로드 성공률 95%+
  - [ ] 예약 게시 (현재+1시간~30일)
  - [ ] 재시도 3회 + 실패 알림

### F7: 크리에이터 대시보드 [P0]
- **완료 기준**:
  - [ ] 커버·플랫폼별 조회·좋아요·댓글 24h 수집
  - [ ] 주간·월간 그래프
  - [ ] Top 3 하이라이트 + 저성과 개선 팁
  - [ ] CSV 내보내기

### F8: 수료 → 데뷔 자동 트리거 [P1]
- **완료 기준**:
  - [ ] 10/20/28단계 도달 시 자동 알림
  - [ ] "지금 첫 MV" 원클릭 진입
  - [ ] 첫 MV 무료 크레딧 자동 지급
  - [ ] 알림→생성 전환 40%+

### F9: MR 라이선스 카탈로그 [P1]
- **완료 기준**:
  - [ ] Phase 1 종료 시 MR 100곡+
  - [ ] 장르 필터 / BPM·키 정보 / 키 자동 매칭 추천
  - [ ] 본인 MR 업로드 시 저작권 체크박스

### F10: 성과 기반 추천 & 리텐션 [P2]
- **완료 기준**:
  - [ ] 월간 인사이트 알림
  - [ ] 선호 장르 기반 신곡 MR 푸시
  - [ ] 월 4곡 미만 유저 리텐션 이메일
  - [ ] 추천→생성 전환 15%+
