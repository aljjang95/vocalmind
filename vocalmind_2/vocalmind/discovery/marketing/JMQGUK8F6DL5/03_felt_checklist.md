# felt 점검 체크리스트와 수정안

작업: JMQGUK8F6DL5  
대상: 현재 랜딩/제품 메시지 + 이번 로컬 마케팅 산출물  
검토 기준: 첫인상, 후킹, 신뢰, 구매/가입 욕구, 브랜드 결

## 1. 첫인상

|항목|판정|근거|수정안|
|---|---|---|---|
|무엇을 하는 서비스인지 3초 내 이해되는가|보통|Hero는 “목이 조이는 이유”를 잘 잡지만, 제품 형태가 “앱/AI 코칭/진단”인지 즉시 선명하지는 않음.|숏폼/카드뉴스 첫 화면에 “30초 녹음 → 4축 긴장 분석”을 붙여 제품 동작을 즉시 노출.|
|톤이 고급스럽고 보컬 서비스답나|좋음|딥 포레스트, 파형, 스튜디오 이미지가 일관됨.|카드뉴스도 같은 색/무드 유지. 너무 튀는 유튜브식 빨간 경고 톤 금지.|
|누구를 위한 것인지 보이나|보통|고음/목조임 문제는 명확하나, 취미·입시·오디션 각각의 상황은 랜딩 후반에 분산됨.|광고 소재는 “고음만 가면 목이 잠기는 사람” 하나로 좁혀 시작.|

## 2. 후킹

|항목|판정|근거|수정안|
|---|---|---|---|
|증상 직격형 문장인가|좋음|“목이 조이는 이유”는 강함.|숏폼 첫 3초는 더 직접적으로 “고음만 가면 목이 잠기나요?” 사용.|
|스크롤/스와이프를 멈추게 하는가|보통|랜딩 Hero는 정적이고 우아함. 숏폼 피드에서는 약할 수 있음.|파형 찌그러짐, 후두 긴장 72점 같은 즉시 변화 컷 사용.|
|차별점이 후킹 안에 들어가는가|좋음|4축 긴장 분석은 강한 차별점.|카드 2장에 4축 바 차트를 빠르게 배치. “AI”보다 “4축”을 먼저 말함.|

## 3. 신뢰

|항목|판정|근거|수정안|
|---|---|---|---|
|기술 근거가 보이는가|좋음|Praat, 후두·혀뿌리·턱·성구전환, 28단계 커리큘럼이 있음.|카피에서 “AI가 다 해줌”보다 “Praat 기반 분석 + AI 코치” 순서 유지.|
|과장/의학적 오해 위험이 없는가|주의|“긴장 감지”는 안전하지만, “목 문제 해결”처럼 들리면 치료 뉘앙스 위험.|“치료/완치/교정 보장” 금지. “분석·피드백·연습”으로 제한.|
|후기 신뢰도가 충분한가|보통|Testimonials는 이름/상황/Before-After가 있으나 실제 인증/근거 이미지는 없음.|광고 1차 소재에는 후기보다 제품 분석 화면 중심. 후기 소재는 추후 실제 스크린샷/동의 확보 후 별도 제작.|

## 4. 구매/가입 욕구

|항목|판정|근거|수정안|
|---|---|---|---|
|진입장벽이 낮은가|좋음|무료 상담, 카드 등록 없음, 18단계 무료가 있음.|모든 광고 CTA는 “유료 플랜”이 아니라 “30초 녹음/무료 상담”으로 통일.|
|가격 설득이 충분한가|보통|랜딩 Pricing은 오프라인 레슨 대비 월 15만원을 보여줌.|초기 광고에서는 가격보다 “내 원인을 지금 확인” 욕구가 더 빠름. 리타겟팅 소재에서 가격 비교 사용.|
|다음 행동이 명확한가|좋음|CTA가 “무료 상담 시작하기”로 명확함.|카드뉴스 마지막 버튼 문구를 “30초 녹음하기”로 구체화.|

## 5. 브랜드 결

|항목|판정|근거|수정안|
|---|---|---|---|
|전문성과 따뜻함이 같이 있는가|좋음|수치 분석과 감각 언어가 균형 있음.|광고에서도 숫자만 밀지 말고 “목 안쪽이 좁게 느껴지나요?” 같은 감각 문장을 포함.|
|AI 서비스처럼 차갑게 보이지 않는가|좋음|코치 말투/감각 설명이 사람 레슨에 가까움.|AI 코치 컷은 말풍선 UI로 부드럽게 표현.|
|기존 랜딩과 시각적으로 이어지는가|좋음|딥 포레스트/에메랄드/라운드 카드/파형 사용 가능.|HTML 프리뷰는 현재 CSS 토큰을 반영해 제작.|

## 우선 수정안 TOP 5

1. 광고 첫 문장은 “목이 조이는 이유”보다 더 상황형인 “고음만 가면 목이 잠기나요?”로 시작.
2. “AI”보다 “30초 녹음 → 후두·혀뿌리·턱·성구전환 4축 분석”을 먼저 보여줌.
3. 모든 1차 퍼널 CTA는 “무료 상담 시작/30초 녹음”으로 고정하고 유료 플랜은 후순위.
4. 신뢰 컷은 후기보다 실제/모사 분석 UI를 우선 사용. 후기 광고는 증빙 확보 후 별도 제작.
5. 금지 표현을 명문화: 완치, 치료, 보장, 무조건 고음 가능, 의학적 진단.
